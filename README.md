# AI小説生成用ツール

## これはなに

＊ Aionの新バージョンが出たので試しに使ってみようかと小説を書かせるツールを作りました
* 汎用ハーネスでエージェントループを回して章ごとに生成します（今回はHermesAgentを使いましたがなんでもいいです、モデルも相当おバカじゃなければたぶんなんでもOK）

## 使い方

* 汎用ハーネスが処理する用のAGENTS.md作成
* ちょっと賢いAI（今回はClaudeOpus5.5）を使って壁打ちして物語の骨格や構成を書いたBRIEF.mdを作成
* 接続情報やプロンプトの基礎、章立てを書いたconfig.json作成（Claudeが作ってくれる）
* 汎用ハーネスにAGENTS.mdとBRIEF.mdとconfig.jsonを汎用エージェントに食わせて「これに従ってAionをこき使って小説書かせろ」と指示
* 汎用ハーネスはnovelctl.pyを延々と回してAionに小説を書かせる（エージェントループ）
* 完成したらClaudeで構成し、表紙や口絵を描いてもらってEPUB化する
